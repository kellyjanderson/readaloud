# Architectural change design issues

Read AGENTS.md and docs/project-management.md#directed-work, then the current issue and affected architecture/source. Load only applicable conditional procedures; before dispatch or delegation read #conditional-orchestration. Draft substantial ACDs in Git-tracked project/interim/<revision>/ using its lifecycle guide; never store designs in tmp/. Use TEMPLATE.acd for the design structure. Publish the reviewed revision to its GitHub design issue and retain a fixed, source-linked snapshot in Git, not a synchronized issue-body copy. Include problem, outcome, exclusions, ownership/concurrency, migration, acceptance and reconciliation targets. Record material decisions with revision identity. GitHub current blocks and Project Status own execution; comments retain decision history. Link bounded sub-issues without recursive spec trees. Reconcile implemented architecture and evidence before retiring interim files in a reviewed Git change or closing the design.
