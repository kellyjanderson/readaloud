# UI Guide Distillation

When broad UI-system documents change, distill the implementation-relevant decisions into direct local operating rules.

## Source Guides

At minimum, watch:

* `project/ui/brand-guide.md`
* `project/ui/design-guide.md`
* `project/ui/component-system.md`

## Distillation Rule

Do not leave major UI-system decisions only in broad guide prose.

Extract durable operational guidance for:

* brand voice
* terminology
* typography
* color direction
* workspace rules
* component rules
* desktop navigation expectations

## Maintenance Rule

When the broad guides change, update the local distilled rules in the same pass so agents do not have to re-derive the decisions from scratch later.
