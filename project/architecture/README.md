## Evidence and acceptance limits

- [P0 baseline](https://github.com/kellyjanderson/readaloud/issues/49#issuecomment-6393427541): native arm64 toolchain and separated source/bundle/runtime asset provenance; cached runs do not attest fresh inference.
- [P1 preparation](https://github.com/kellyjanderson/readaloud/issues/50#issuecomment-6393533201): worker/revision tests and native input during a large preparation, replacement, publication and scrolling on bounded fixtures. Observation times are not frame-time bounds.
- [P2 resources](https://github.com/kellyjanderson/readaloud/issues/51): resident A/B/A resource/cleanup, failure and normal-app replay evidence. Retained handles, memory, emitted PCM and listening answer different questions.
- [P3 accepted working-branch integration](https://github.com/kellyjanderson/readaloud/issues/52#issuecomment-6395174262): bounded planning/synthesis and native queue/export matrix. The [copied-audio audit](https://github.com/kellyjanderson/readaloud/issues/52#issuecomment-6395019641) verifies complete emitted PCM concatenation; it does not prove acoustic continuity. Eight seconds is an admission threshold plus one in-flight chunk, not a hard maximum.
- [P4 accepted resource/cache run 2](https://github.com/kellyjanderson/readaloud/issues/53#issuecomment-6395918850): source `25f1dfe` adds a harness-only private-copy repair to the `295677e` production lineage. Actual resident stale-request rejection, unchanged-content reuse, same-ID voice-byte/model-digest misses, incomplete regeneration and corrupted metadata rejection passed. Four inferences, two balanced native session opens/closes, peak one session/four tensors and final zero/zero were recorded; this is not an isolated RSS or playback/acoustic benchmark. Failed run 1 remains a preserved copy-permission failure.
- [P4 assignment295 prefix audit](https://github.com/kellyjanderson/readaloud/issues/53#issuecomment-6395976458): pending edits preserved source/position/hash; Apply's first new source began at word 8 before acknowledgment; latest C won initial A/B/C startup; pause retained pins and stop cleared them. Three exports exactly matched ordered chunk PCM. The [terminal handoff](https://github.com/kellyjanderson/readaloud/issues/53#issuecomment-6396083722) records failure after a 30-minute listening timeout, followed by zero sessions/tensors/sources/pins/tasks. Valid prefix observations do not make this failed run a pass. Modal open overlapped one owned producer; Close transitioned from one to zero, and scroll/Recenter ran with zero. Every actual input had export inactive. Menu dismissal is unproved; debug frame timing includes stalls and is not input latency or CPU-planning acceptance.
- [P4 supplemental native run](https://github.com/kellyjanderson/readaloud/issues/53#issuecomment-6396165816): immutable `e18c81d` bundle (71 files/seven native images attested) exited zero after paused pending Play, injected pre-ack failure/retry, held-export cancellation/pin drainage, stale A/B/C failure and A/B/A PCM checks. Four exports strictly decoded and exactly matched ordered chunks; 135 unique artifacts were validated. The [root acceptance audit](https://github.com/kellyjanderson/readaloud/issues/53#issuecomment-6396216177) also found A1 byte-for-byte identical to the accepted P3 export and accepted these automated cases within diagnostic limits. Peak one session/four tensors; final zero sessions/tensors/sources/pins/tasks. The diagnostic assembly hold is waiting, not CPU-heavy work. CUA binding timed out and actual UI action count was zero, with the blocker recorded before diagnostic release. Muted playback and readiness signals do not establish listening or input-under-export acceptance.
- [Saved-word resume interpretation](https://github.com/kellyjanderson/readaloud/issues/53#issuecomment-6396190387): native no-edit resume retained word 293 but replaced the source and reset player position. Baseline `694e1c3` already rebuilt the saved-word tail through `engine.speak`, which stops the previous generation. No new source-level regression is identified; neither sample-continuous resume nor a fresh native baseline comparison is established.
- [Bounded P4 modal/status smoke](https://github.com/kellyjanderson/readaloud/issues/53#issuecomment-6395513249): real app/control layering and named Close/status dismissal, with an identified status-only probe and API seam. It does not establish final assignment behavior; native Escape remains unproven.

Input during active export remains blocked and human listening remains unverified. P0–P3 have reached the working integration branch. This P4 source description is not a main merge or feature-completion claim.
