### Directed implementation sequence and concrete changes

**0 — Use the completed baseline.** Verify current branch/head and preserved WIP; retain #122 release ownership. No new merge/tag/branch purge/layout pass. Native test sessions use isolated profiles and own normal Quit/process-exit receipts. This step is verification at entry, not another integration project.

**1 — Repair the attribution boundary regression (A1 / #125, design #124).** Add the published failing Alice/Bob oracle; introduce source-coordinate-aware context/checkpoints and stale-revision protection in import/attribution. Preserve unknowns and the accumulated cast UI. Exit: split/whole mandatory cases, replay/cancel/cross-work tests and bounded memory pass. User result: dialogue stops changing speaker merely because preparation crossed a fragment boundary. This is the first code change.

**2 — Establish the short real Drama checkpoint (existing #111, M1/F1 qualification).** Use the current snapshot if valid; otherwise use the app's downloader. Verify complete offline reuse and correct displayed progress, fixing only observed blockers. Play a manually checked private City passage through its ending at native rate; exercise stop/pause/seek/export and normally Quit. Capture exact model/reference/runtime identity and actual emitted output/listening. Routine weight-dependent tests may be optional, but an omitted native check is not a pass. User result: a complete usable Drama reading baseline before general refactoring. If runtime ownership prevents this, pull only the required R1 fix forward and record why.

**3 — Bound reading and finish lifecycle ownership (R1 / #113).** Replace million-chunk planning with demand batches/lead budgets; remove unnecessary eager engine creation; extract neutral session responsibility while retaining the player/admission/artifacts. Exit: slow/stale child and adjacent-operation cases, bounded queues/memory with growing books, responsive cancel, no unexpected speech and verified shutdown. User result: large stories and interrupted operations stay controllable.

**4 — Persist work characters and voice intent (C1 / #126, design #124).** Add work/character identity and versioned evidence/voice records; migrate exact-source choices and Reset additively; retain distinct stated/inferred/contextual gender. Exit: reopen/cache-loss/edit association/merge-split/two-work/engine-round-trip fixtures and private running-app choices. User result: the book remembers its cast and explicit voice choices independently of analysis cache or engine.

**5 — Qualify the local attribution provider (A2 / #127, design #124).** Implement the data-only provider boundary, pinned isolated runtime/acquisition and bounded request lifecycle; run the fixed held-out/City comparison against repaired heuristics. Publish a promotion or measured non-promotion decision before enabling it. User result: demonstrably better attribution if it qualifies, with no whole-book startup gate or hidden model downloads. This evaluation can proceed after A1/C1 interfaces stabilize; Fish scenes do not wait for neural-provider promotion.

**6 — Implement portable scenes and native Fish voice reuse (S1 / #111).** First land descriptor/capability and immutable scene/binding/piece contracts, coordinated with M1; then Fish multi-reference lowering and bounded conditioning reuse; then a second engine adapter path using the same contract. Preserve #120 exact-model scopes. Exit: five usable choices per character, narrator/A/B/A identity/ending, no model reload on character changes, native-rate export, accurate alignment claims, measured cache benefit and second-engine reuse. User result: efficient character switching and useful shared infrastructure rather than competing voice systems.

**7 — Complete acquisition, live variants and feedback qualification (M1/F1 / #112/#119).** Finish one descriptor-driven catalog, validated snapshots, cancel/resume and latest-wins transitions; retain installed models across rebuilds and explicit character intent. Prove A/B/A and rapid A/B/C under download/load/read/export; qualify quality-first memory admission on M5 and the actual identified M3. Check quiet summary/Activity and terminal errors in the app. User result: compatible 8-bit/4-bit changes without app restart/rebuild, truthful progress and no repeated complete downloads. The descriptor slice may precede Step 6; the switch/hardware acceptance follows R1/S1. Do not interpret these two partial dependencies as a circular whole-issue dependency.

**8 — Consolidate the identified remaining duplication (D1 / #114).** Separate reversible slices: RIFF structure, shared import events (DOCX→EPUB→HTML/text), document-envelope encoding after C1, production-backed probes after M1/S1. Optional small traversal/lifecycle/bookmark helpers only with net simplification. Exit: removed duplicate code and preserved richer format/mapping/audio semantics, bounded memory and appropriate native comparisons. User result: one fix reaches every consumer without constraining better engines. This does not delay Step 2.

**9 — Reconcile product presentation and agent entry (P1/G1 / #115/#116).** Two separately owned changes: correct remaining current architecture/setup/support matrix/media against the actual candidate; then compact directives/templates with a rule-survival map and measured real-task re-entry. Completed file cleanup stays completed. User result: clear onboarding and less repeated agent context, with safety/product rules retained. Independent of the product critical path; no fabricated token savings.

**10 — Qualify the integrated release (#122 with #83/#91/#55).** Freeze an exact candidate after required feature acceptance; run local integration/package checks and installed-app City reading, full ending, persisted `.radoc`, voice controls, model reuse/switching, long-session continuity/memory and normal Quit. The two-second opening-to-speech requirement remains from app opening; cold download/load delays remain visible gaps. Human listening follows engineering checks. Reconcile architecture/docs and legal/runtime/model notices. Actual M3 information, any unmet timing/quality gate and publication decisions remain explicit. Merge/publish only under required user authorization; validate/build actual main artifacts before immutable tagging. No new release is authorized by R10.
