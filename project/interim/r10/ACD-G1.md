### Decision and ownership
Keep AGENTS.md as the single repository authority, with a compact default path for directed work. Retain product invariants, current-context entry, WIP preservation, named concurrency ownership, audio/native proof, no paid Actions, GitHub planning and release authorization. Move detailed dispatch/worktree/model/counter procedures behind an explicitly linked conditional orchestration section in the existing process guide. Moving a rule changes where it is loaded, not its force or approval threshold.

Create a rule-survival map in this issue's implementation receipt: existing rule → retained concise rule or exact conditional destination → verification scenario. Avoid a second local policy ledger. The document editor owns AGENTS and process guidance together; templates/skills consume that authority instead of restating it. No global agent roles or home-level instructions are modified.

### Entry and templates
Default entry reads README/project map/process entry, parent/assigned current blocks, the assigned ACD section and changed affected source. Re-entry uses current block and changed evidence, not full review/comment archives. Preserve `read_issue_context.rb` bounded retrieval and stale-block failure behavior. A current block is an index, not a waiver of the contract.

Keep `acd` and `implementation-plan` as distinct thin routes for design and execution. Make worker/model/worktree fields conditional in visitor and small-fix templates while retaining actual base/target, scope, test limits and missing acceptance. A small fix may remain one issue; no synthetic parent plus children is required. Review retired local stubs against unique rules, then use verified live SkillsKeeper source/archive machinery to disable/archive them. Do not edit generated global copies or overwrite managed sources from an old worktree.

### Coordination, migration and proof
Single directed owner is the default. Delegation remains available only under applicable user/process authorization with exclusive ownership and isolated conflicting writes. Preserve fresh-context work orders, model/effort and escalation rules in the conditional procedure. Issue current-block writes are serialized and re-fetched; no parallel edits to the same checkout/index. No subagents are dispatched by this plan.

First capture current rule map and one naturally occurring task/re-entry baseline; then change routing/templates; then run a comparable directed task and re-entry. Measure context/payload sizes, coordination writes, turns, elapsed time and actual token fields if available. Do not invent costs/savings or run unnecessary artificial agent traffic. Verify no lost product constraints, approval thresholds, source/runtime proof distinction, WIP protection or current-block discovery. Review failure restores the prior instructions via Git/managed source rollback.

Files: AGENTS.md, docs/project-management.md, relevant `.github` templates and repository-owned skill sources. No product runtime/async producer is introduced. Reconcile human process guidance and SkillsKeeper registration/validation receipts. Independent of product features, bounded and scheduled after the first Drama checkpoint unless it blocks safe work; never a precondition for audible speech.
